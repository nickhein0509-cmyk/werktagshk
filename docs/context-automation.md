# Kontextprüfung und begrenzte automatische Korrektur

Die App-CI prüft den Produktindex gegen die Produkttabelle in `docs/product-map.md`. Bei einer Abweichung wird ein korrigierter Index als CI-Artefakt bereitgestellt; lokal erzeugt `node scripts/context-index.mjs --write` denselben Index. Die Prüfung beweist weder die Aktualität der Produktkarte noch die inhaltliche Richtigkeit eines Designauftrags. Der Designumfang im PR ist eine Erklärung der Bearbeitenden und muss überprüft werden.

Der Workflow `Produktindex-Korrektur vorbereiten` prüft nach relevanten Änderungen auf `main`, täglich und auf manuellen Start. Er führt nur Skripte des aktuellen `main` aus. Wenn der Index von der Karte abweicht, erstellt er einen PR, der ausschließlich `docs/generated-product-index.md` ändert. Er führt keinen automatischen Merge aus. Ein bereits offener automatischer Index-PR wird nicht überschrieben; dessen Aktualität und CI-Status sind zu prüfen. Ändert sich `main` während des Laufs, bricht er vor dem Push ab und ein späterer Lauf versucht es erneut.

Dazu muss das Repository-Secret `WERKTAG_INDEX_REPAIR_TOKEN` mit einem hierfür zugelassenen, entsprechend eingeschränkten Fine-grained-Token eingerichtet und vor dessen Ablauf erneuert werden (nur dieses Repository; `Contents: write` und `Pull requests: write`, mit Zugriff auf die nötigen Metadaten). Token nicht in Git oder Logs eintragen. Ein eigener Token ist nötig, damit der neu erstellte PR die üblichen GitHub-Actions-Ereignisse auslösen kann. Repository-Regeln oder Branch-Schutz können weitere Voraussetzungen setzen. Ohne Token schlägt nur ein notwendiger Korrekturlauf mit einem erklärenden Fehler fehl; bei aktuellem Index braucht der Lauf keinen Token. Die Funktion ist erst aktiv, wenn Workflow und Token eingerichtet und ein tatsächlicher Testlauf geprüft wurden.

Ein automatischer Aufgabenbranch kann eine Hosting-Vorschau auslösen. Der Zugriffsschutz und die tatsächlichen Deployment-Regeln sind vor Aktivierung zu prüfen. Die Reparatur verändert weder Produktcode noch Konfiguration und ändert keine Zugriffsrechte. Für weitere Fehler oder inhaltliche Widersprüche erzeugt sie keine automatische Lösung.
